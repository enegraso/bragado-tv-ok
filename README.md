# 📺 Bragado TV

Aplicación multiplataforma desarrollada con **Expo + React Native** para transmitir en vivo la señal de **Bragado TV**, con soporte para:

- 📱 Android Mobile  
- 📺 Android TV (Leanback)  
- 🍏 iOS  
- 🖥️ Smart TV compatibles con Android TV  

Incluye actualización remota de stream, detección de nuevas versiones y reproducción optimizada para TV.

---

## 🚀 Funcionalidades

- 🎥 Streaming en vivo HLS
- 🔄 Configuración remota de URL de streaming
- 🧭 Detección de actualizaciones en tiendas
- 🖼️ Modo Pantalla Completa por defecto
- 🪟 Picture-in-Picture en móviles
- 📡 Reanudación inteligente al volver a la app
- 📺 Interfaz adaptada para Android TV
- 🧱 Construcción unificada desde una sola base de código

---

## 🛠️ Tecnologías

- **Expo SDK**
- **React Native**
- **JavaScript**
- **expo-video**
- **EAS Build**
- **Expo Updates**
- **Android TV (Leanback)**
